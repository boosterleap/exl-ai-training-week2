# Week 2 data — two parallel threads

Two domains run in parallel all week. **Insurance** is the primary thread used for
concept exploration and guided hands-on in every AM/PM session. **Logistics** is the
transfer-exercise thread: participants apply the same day's concept independently,
partly in-session and partly as homework.

## Insurance — Automated Ticket / Email Resolution Assistant

| File | What it is |
|---|---|
| `insurance/fnol_emails.csv` | 12 inbound customer emails to triage/respond to (ground-truth category, urgency, claim, route queue, policy included for grading your own agent's output) |
| `insurance/claims.db` (SQLite: `policies`, `claims`) | Structured lookup — the "database" a tool call resolves `policy_id` / `claim_id` against |
| `insurance/policies/*.md` | Product-level policy terms & conditions (10 files) — the RAG corpus |
| `insurance/policy_chunks.json` | Pre-chunked version of the same corpus, for reference/comparison once participants build their own chunker |
| `insurance/customer_sessions/threads.json`, `insurance/claim_narratives_10.json`, `insurance/workflow_cases_15.json`, `insurance/rag_goldens.json` | Supporting fixtures for memory, multi-agent, and RAG-eval exercises later in the week |

**Product → policy doc mapping** (join `claims.policy_id` → `policies.product`, then match the doc prefix):

| `product` | Policy doc prefix |
|---|---|
| `homeowners` | `POL-HOME-010` |
| `auto` | `POL-AUTO-001` |
| `commercial_property` | `POL-COMM-030` |
| `landlord_liability` | `POL-LL-040` |

## Logistics — Delivery Exception & Delay Automation

| File | What it is |
|---|---|
| `logistics/customer_emails.csv` | 11 inbound customer emails, same shape as the insurance CSV |

## Regenerating the databases

Both SQLite databases are generated by a small, readable seed script rather than committed as an opaque binary edit target:

```bash
uv run python data/insurance/seed_claims_db.py
uv run python data/logistics/seed_shipments_db.py
```

Re-run either script at any point to reset that database to its original seed state.
