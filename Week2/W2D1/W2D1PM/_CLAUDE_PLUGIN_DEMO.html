Permission / write teaching flags (conceptual — say aloud)

Notebook cells use env-style gates. In the plugin demo you narrate the same four gates; do not actually release holds unless you intentionally arm them:

  1. ALLOW_LOCAL_WRITES
  2. ALLOW_HOLD_RELEASE
  3. LEARNER_APPROVED_HOLD_RELEASE
  4. HOLD_RELEASE_IDEMPOTENCY_KEY (12+ chars, non-placeholder)
Default classroom posture: all four off / not approved → show ReleaseProposal only and write_skipped: true.

Chronological live demo (follow in order)

Scroll _DEMONSTRATIONS.ipynb to the matching section while you run each step.

  1. §01 — Claude Agent SDK concepts via plugin

    Teaching point: plugin chat ≈ the same agent loop the SDK exposes as query(); metering still matters.

    Slash: /day1-pm-sdk-query

    /day1-pm-sdk-query

Explain in two sentences why an agent must use domain tools instead of inventing claim facts.

Remind learners this path uses Claude Code login, not ANTHROPIC_API_KEY.

    Expected: tool-grounding explanation + ResultMessage-shaped JSON; cost string notes subscription metering.

  2. §01b — Session memory (ClaudeSDKClient story)

    Turn A: Remember this operating rule for the rest of this chat:

(Wait for reply, then send Turn B in the SAME Claude chat thread)

Turn B: What operating rule did I ask you to remember?
Answer with the exact rule text only.

    Expected: same-thread recall — maps to ClaudeSDKClient multi-turn sessions in the notebook.

    Say aloud: “One-shot query() forgets; a client/session remembers.”

  3. §02 — Built-in Read vs custom / MCP tools

    Slash: /day1-pm-tools

    /day1-pm-tools

1) Use Read on CLAUDE.md and state the first operator rule.
2) Explain MCP-style names: mcp__insurance__fnol_lookup, claim_lookup, policy_lookup.

   with evidence-backed case_id starting CLM-.

  4. §03 — Structured outputs & message blocks

  5. §03b — Logistics shipment lookup (no write)

  7. §05 — Permissions, can_use_tool, hold-release gate

Troubleshoot / talking points

  • Learners ask for API keys — “Not for this demo. Claude plugin login is enough. Notebooks that call query() need keys — we are not running those cells now.”
  • Wrong MCP names — correct to mcp__insurance__* when server key is insurance (not mcp__ops__*).
  • Agent claims hold released — stop; re-run /day1-pm-permissions; emphasize proposal vs write.
  • AM artifacts still loaded — reopen folder as W2D1PM so PM skills/hooks apply.
  • Timebox — if short: Steps 1 → 3 → 7 (SDK shape, tools/triage, permissions).
