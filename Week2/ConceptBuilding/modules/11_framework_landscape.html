Why this module exists

The same model can swing roughly ~30 points on hard agent benchmarks (e.g. GAIA) depending on orchestration scaffold: retries, typed tools, checkpoints, HITL placement, and budgets. Architecture reliability is not only a model-quality problem.

Lab depth vs slide literacy Week 2 labs go deep on LangGraph (graph state, SQLite checkpoints, durable HITL) and Claude Agent SDK (tools, sessions, permissions, hooks). CrewAI, OpenAI Agents SDK, Google ADK, and Microsoft Agent Framework appear in comparison tables only. Managed clouds (Bedrock AgentCore, Vertex Agent Builder, Azure AI Foundry, Anthropic Managed Agents) are enterprise concepts — learners use local mocks instead.

GraphRAG cost note (~3–5×)

GraphRAG (entity/relation extract → knowledge graph → traverse + vector search) helps multi-hop questions like “who supplies whom.” It often costs ~3–5× a single-pass RAG path (extraction, storage, traversal tokens). Use it when relationships matter; otherwise stay hybrid vector + keyword. Lab depth uses NetworkX + local fixtures (module 15), not paid Neo4j Aura.

Claude Agent SDK isolation spectrum (review)

LevelIsolationHandoffTypical use
Skills Shared context with parent None (same session) Policy lookup skill in one chat
Sub-agents Isolated context One-way result → parent Claims worker returns a summary only
Agent teams Separate processes (experimental) Message protocol Parallel ownership, harder boundaries
Model roles Stronger orchestrator (e.g. Opus-class) for planning/routing; cheaper workers (e.g. Sonnet-class) for narrow tool work. Avoid sub-agent sprawl — context, cost, and OOM risk multiply.

Exercise I6 · Cost estimator for GraphRAG vs hybrid
def estimate_relative_cost(mode: str, base_usd: float = 0.02) -> dict:
  if mode == "hybrid_rag":
    mult = 1.0
  elif mode == "graphrag":
    mult = 4.0  # midpoint of 3–5×
  else:
    raise ValueError(mode)
  return {"mode": mode, "est_usd": round(base_usd * mult, 4), "multiplier": mult}

h = estimate_relative_cost("hybrid_rag")
g = estimate_relative_cost("graphrag")
assert g["est_usd"] == h["est_usd"] * 4
print(h, g)
print("Only pay GraphRAG tax when relationships are the product question.")

Exercise A8 · GraphRAG go / no-go with budget gate
def graphrag_gate(monthly_rag_usd: float, relation_questions_pct: float) -> dict:
  # If <15% of questions need multi-hop, 4× cost rarely pays
  projected = monthly_rag_usd * (1 + relation_questions_pct * 3)  # rough blend
  go = relation_questions_pct >= 0.15 and monthly_rag_usd * 4 < monthly_rag_usd * 6
  return {
    "go_graphrag": relation_questions_pct >= 0.20,
    "hybrid_ok": relation_questions_pct < 0.20,
    "note": "lab still demos NetworkX concept even if prod stays hybrid",
    "projected_blend_usd": round(projected, 2),
  }

g = graphrag_gate(1000, 0.05)
assert g["hybrid_ok"] is True
assert graphrag_gate(1000, 0.35)["go_graphrag"] is True
print(g)
Exercise A9 · Isolation spectrum review exam (mixed)
exam = [
  {"prompt": "Shared glossary skill", "expect": "skill"},
  {"prompt": "Isolated fraud review returning JSON only", "expect": "sub_agent"},
  {"prompt": "Separate process team (experimental)", "expect": "agent_team"},
  {"prompt": "Orchestrator Opus + worker Sonnet", "expect": "model_roles"},
]

def grade(prompt: str) -> str:
  p = prompt.lower()
  if "opus" in p or "sonnet" in p:
    return "model_roles"
  if "separate process" in p or "team" in p:
    return "agent_team"
  if "isolated" in p or "returning" in p:
    return "sub_agent"
  return "skill"

score = sum(1 for item in exam if grade(item["prompt"]) == item["expect"])
assert score == len(exam)
print(f"exam {score}/{len(exam)}")
