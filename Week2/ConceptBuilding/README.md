# Week2/ConceptBuilding — Instructor mastery track

Open [index.html](index.html) in a browser.

Each `modules/*.html` page is a long-form guide with Beginner / Intermediate /
Advanced exercises. Copy code into a Jupyter notebook whose working directory is
`Week2/ConceptBuilding` (or fix relative paths to `data/`).

- **Windows PowerShell** blocks (dark code style)
- **Ubuntu / bash** blocks (light purple background)
