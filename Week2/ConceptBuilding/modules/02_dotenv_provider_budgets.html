Why this matters

Week 2 does not ship separate _openrouter folders. The same W2D* code reads LLM_PROVIDER at runtime and branches. Budget knobs keep learner loops cheap: fewer tool turns, capped output tokens, and (on Anthropic) a hard dollar stop per run.

Never commit .env Copy Week2/.env.example to Week2/.env, fill keys locally, and leave .env in .gitignore. Never paste keys into notebooks, screenshots, chat, or HTML. This guide uses empty placeholders only — matching the example file.

The standalone example mirrors the provider-selection concepts in W2D1/W2D1PM/_CONCEPTS.ipynb: load_dotenv(WEEK2_ROOT / ".env"), then build a settings dict with max_steps, max_tokens, and max_budget_usd.

def find_week2_root(start: Path | None = None) -> Path:
  """Walk parents until Week2/.env.example is found."""
  here = (start or Path.cwd()).resolve()
  for candidate in [here, *here.parents]:
    if (candidate / ".env.example").exists() and candidate.name == "Week2":

Hard stops vs soft thresholds

Cost awareness on Day 1 PM depends on knowing which knobs actually abort a run versus which ones only annotate or truncate a single call.

KnobAnthropic (Claude Agent SDK)OpenRouter (LangGraph)
AGENT_MAX_STEPS Hard — maps to max_turns Hard — recursion limit derived from max steps
AGENT_MAX_BUDGET_USD Hard — max_budget_usd per run Recorded in cost log; not an SDK hard abort (track manually / trainer policy)
AGENT_MAX_TOKENS Soft / post-run — usage compared after the run; may mark token_budget_exceeded Per-call hard cap — passed as model max_tokens
Operator rule of thumb Steps always stop the loop. Dollars stop Anthropic runs. Tokens clip OpenRouter completions immediately, but on Anthropic they are a post-run threshold for the cost object — useful for dashboards and learner feedback, not a mid-turn abort.

Raise ValueError for anything other than the two allowed values.

def validate_provider(raw: str | None) -> str:
  provider = (raw or "anthropic").lower().strip()
  allowed = {"anthropic", "openrouter"}
  if provider not in allowed:
    raise ValueError(f"LLM_PROVIDER must be one of {sorted(allowed)}, got {provider!r}")
  return provider

print(validate_provider(os.getenv("LLM_PROVIDER")))

Exercise A1 — Simulate hard step counter stop

Fake tool turns until AGENT_MAX_STEPS. Stop when index exceeds the cap (same idea as reliability demos). 

def simulate_steps(max_steps: int, planned_turns: int) -> dict:
  steps_used = 0
  stopped_reason = "completed"
  for index in range(1, planned_turns + 1):
    if index > max_steps:
      stopped_reason = "max_steps"
      break
    steps_used = index
  return {"steps_used": steps_used, "max_steps": max_steps, "stopped_reason": stopped_reason}

print(simulate_steps(max_steps=3, planned_turns=10))
assert simulate_steps(3, 10)["stopped_reason"] == "max_steps"
assert simulate_steps(10, 4)["stopped_reason"] == "completed"
Exercise A2 — Simulate Anthropic hard budget stop

Accumulate fake USD spend; abort when spend would exceed max_budget_usd.

def simulate_budget(max_budget_usd: float, step_costs: list[float]) -> dict:
  spent = 0.0
  steps_used = 0
  stopped_reason = "completed"
  for cost in step_costs:
    if spent + cost > max_budget_usd:
      stopped_reason = "max_budget_usd"
      break
    spent += cost
    steps_used += 1
  return {
    "steps_used": steps_used,
    "total_cost_usd": round(spent, 4),
    "max_budget_usd": max_budget_usd,
    "stopped_reason": stopped_reason,
  }

print(simulate_budget(0.05, [0.02, 0.02, 0.02, 0.02]))
assert simulate_budget(0.05, [0.02, 0.02, 0.02])["stopped_reason"] == "max_budget_usd"

Exercise A4 — Anthropic post-run token threshold

After a finished run, compare total tokens to AGENT_MAX_TOKENS. If over, set stopped_reason to token_budget_exceeded (does not rewind the run). 

def anthropic_post_run_tokens(
  input_tokens: int,
  output_tokens: int,
  max_tokens: int,
  prior_reason: str = "completed",
) -> dict:
  total = input_tokens + output_tokens
  reason = prior_reason
  if total > max_tokens:
    reason = "token_budget_exceeded"
  return {
    "input_tokens": input_tokens,
    "output_tokens": output_tokens,
    "total_tokens": total,
    "max_tokens": max_tokens,
    "stopped_reason": reason,
    "enforcement": "post_run_threshold",
  }

print(anthropic_post_run_tokens(5000, 4000, 8000))
assert anthropic_post_run_tokens(5000, 4000, 8000)["stopped_reason"] == "token_budget_exceeded"
assert anthropic_post_run_tokens(1000, 500, 8000)["stopped_reason"] == "completed"
Exercise A5 — Combined loop simulator

Apply step hard-stop first, then budget hard-stop (Anthropic path mental model).

def simulate_anthropic_run(
  max_steps: int,
  max_budget_usd: float,
  max_tokens: int,
  events: list[dict],
) -> dict:
  # events: [{"cost_usd": 0.01, "in_tok": 100, "out_tok": 50}, ...]
  spent = 0.0
  in_tok = out_tok = 0
  steps_used = 0
  stopped_reason = "completed"
  for i, event in enumerate(events, start=1):
    if i > max_steps:
      stopped_reason = "max_steps"
      break
    if spent + event["cost_usd"] > max_budget_usd:
      stopped_reason = "max_budget_usd"
      break
    spent += event["cost_usd"]
    in_tok += event["in_tok"]
    out_tok += event["out_tok"]
    steps_used = i
  cost = {
    "steps_used": steps_used,
    "max_steps": max_steps,
    "input_tokens": in_tok,
    "output_tokens": out_tok,
    "total_tokens": in_tok + out_tok,
    "max_tokens": max_tokens,
    "total_cost_usd": round(spent, 4),
    "max_budget_usd": max_budget_usd,
    "stopped_reason": stopped_reason,
  }
  if cost["total_tokens"] > max_tokens and stopped_reason == "completed":
    cost["stopped_reason"] = "token_budget_exceeded"
  return cost

demo = simulate_anthropic_run(
  max_steps=10,
  max_budget_usd=0.50,
  max_tokens=8000,
  events=[
    {"cost_usd": 0.04, "in_tok": 2000, "out_tok": 500},
    {"cost_usd": 0.05, "in_tok": 2500, "out_tok": 800},
  ],
)
print(demo)

def allow_provider_run(settings: dict, dry_run: bool, key_ok: bool) -> tuple[bool, str]:

Tie-in: Week 2 Day 1 PM cost awareness
