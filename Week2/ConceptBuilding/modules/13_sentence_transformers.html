Why this module

Day 3 retrieval is not “call Chroma and hope.” Operators need a mental model for two stages:

  1. Retrieve — fast bi-encoder embeddings + optional keyword score (recall).
  2. Rerank — slower cross-encoder over query–document pairs (precision).

Module 12 explains the runtime-deferred Chroma alternative. This module builds and scores vectors used by the primary Pinecone path. Module 14 is a supplemental LlamaIndex comparison; the teaching implementation uses native Pinecone clients and LangGraph. Classroom eval targets live in data/rag_goldens.json; source text is under data/policies/.

Bi-encoder anatomy (what encode does)

A bi-encoder runs the transformer once per text and pools token states into a fixed vector. Query and document are encoded independently, so you can precompute all policy chunk vectors and compare with cosine (or dot product if L2-normalised).

A cross-encoder concatenates query and document, attends jointly, and emits one score. Too slow for the full corpus; perfect for top-5 / top-20 candidates. 

from sentence_transformers import SentenceTransformer, util

encoder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

docs = [
    "Rental reimbursement after theft up to USD 40 per day.",
    "Flood rider does not cover sewer backup alone.",
]
q = "Is rental car covered after theft?"

doc_emb = encoder.encode(docs, normalize_embeddings=True, show_progress_bar=False)
q_emb = encoder.encode(q, normalize_embeddings=True, show_progress_bar=False)

# util.cos_sim works with lists or 2-D arrays; with normalize_embeddings=True,
# scores ≈ dot products in [-1, 1]
scores = util.cos_sim(q_emb, doc_emb)  # shape (1, n)
print(scores)

Core pattern — SentenceTransformer.encode

from sentence_transformers import SentenceTransformer
import numpy as np

encoder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

texts = [
    "Burst pipe water damage under homeowners policy.",
    "MRI prior authorization for outpatient imaging.",
    "Shipment delayed at customs warehouse.",
]
emb = encoder.encode(
    texts,
    batch_size=16,
    normalize_embeddings=True,
    convert_to_numpy=True,
    show_progress_bar=False,
)
print(emb.shape)          # (3, 384)
print(emb.dtype)          # float32
# L2 norms ≈ 1.0 when normalize_embeddings=True
print(np.linalg.norm(emb, axis=1))

Cosine without sklearn

from sentence_transformers import util

# Pairwise matrix
sim = util.cos_sim(emb, emb)  # (3, 3) tensor
print(sim)

# Or explicit formula on numpy rows
def cosine(a, b):
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-12))

print("0 vs 1:", round(cosine(emb[0], emb[1]), 3))

Intermediate Policy corpus + CrossEncoder

Load real Day 3 fixtures, chunk naively by markdown headings, embed, then rerank the dense shortlist with the MS MARCO MiniLM cross-encoder.

Load data/policies

from pathlib import Path
import re

POLICIES = Path("data/policies")
assert POLICIES.is_dir(), "Run notebook from Week2/ConceptBuilding (or fix path)"

def load_heading_chunks(root: Path) -> list[dict]:
    """Split each policy markdown on ## headings into searchable chunks."""
    chunks = []
    for path in sorted(root.glob("*.md")):
        text = path.read_text(encoding="utf-8")
        policy_id = path.stem.split("_")[0]  # e.g. POL-AUTO-001
        # Keep H1 body + each ## section
        parts = re.split(r"(?m)^##\s+", text)
        preamble = parts[0].strip()
        if preamble:
            chunks.append({
                "chunk_id": f"{path.stem}#preamble",
                "policy_id": policy_id,
                "path": str(path),
                "text": preamble,
            })
        for block in parts[1:]:
            lines = block.splitlines()
            heading = lines[0].strip()
            body = "\n".join(lines[1:]).strip()
            slug = re.sub(r"[^a-z0-9]+", "-", heading.lower()).strip("-")
            chunks.append({
                "chunk_id": f"{path.stem}#{slug}",
                "policy_id": policy_id,
                "path": str(path),
                "heading": heading,
                "text": f"{heading}\n{body}",
            })
    return chunks

chunks = load_heading_chunks(POLICIES)
print(len(chunks), "chunks from", len(list(POLICIES.glob('*.md'))), "files")
print(chunks[0]["chunk_id"], "→", chunks[0]["text"][:80], "...")

Cross-encoder rerank — CrossEncoder.predict

from sentence_transformers import CrossEncoder

reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")

# Take dense top-5, score (query, passage) jointly
candidate_idxs = [h["corpus_id"] for h in hits]
pairs = [(query, chunks[i]["text"]) for i in candidate_idxs]
ce_scores = reranker.predict(pairs)  # numpy array of floats

reranked = sorted(
    zip(candidate_idxs, ce_scores),
    key=lambda t: float(t[1]),
    reverse=True,
)
for idx, score in reranked:
    print(f"{float(score):7.3f}  {chunks[idx]['chunk_id']}")

Higher scores mean “more relevant” for the MS MARCO-trained checkpoint. Absolute values are not probabilities; use them only for ordering unless you calibrate.

Advanced Hybrid keyword + dense + goldens eval

Pure dense retrieval misses exact clause tokens (“sewer backup”, “prior auth”). Pure keyword misses paraphrase. Day 3’s sketch: blend both, then cross-encode the blend’s top-N — same idea as W2D3/W2D3AM/d3amt2c04_hybrid_rerank_eval.py, but self-contained against ConceptBuilding/data.

Keyword score sketch

import math, re
from collections import Counter

def tokenize(text: str) -> list[str]:
    return re.findall(r"[a-z0-9]+", text.lower())

def keyword_score(query: str, text: str) -> float:
    """Lightweight TF-style overlap (not full BM25)."""
    q = tokenize(query)
    d = tokenize(text)
    if not q or not d:
        return 0.0
    counts = Counter(d)
    score = 0.0
    for tok in set(q):
        tf = counts.get(tok, 0)
        if tf:
            score += 1.0 + math.log(1.0 + tf)
    return score

Hybrid rank sketch

import numpy as np
from sentence_transformers import SentenceTransformer, util

encoder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
corpus_emb = encoder.encode(
    [c["text"] for c in chunks],
    normalize_embeddings=True,
    convert_to_numpy=True,
    show_progress_bar=False,
)

def dense_scores(query: str) -> np.ndarray:
    q = encoder.encode(query, normalize_embeddings=True, convert_to_numpy=True)
    # (n,) cosine since vectors are L2-normalised → dot product
    return corpus_emb @ q

def minmax(x: np.ndarray) -> np.ndarray:
    lo, hi = float(x.min()), float(x.max())
    if hi - lo < 1e-12:
        return np.zeros_like(x)
    return (x - lo) / (hi - lo)

def hybrid_rank(query: str, alpha: float = 0.5, top_n: int = 5) -> list[dict]:
    """alpha * keyword + (1-alpha) * dense, both min-max scaled to [0, 1]."""
    kw = np.array([keyword_score(query, c["text"]) for c in chunks], dtype=np.float64)
    dens = dense_scores(query).astype(np.float64)
    combined = alpha * minmax(kw) + (1.0 - alpha) * minmax(dens)
    order = np.argsort(-combined)[:top_n]
    out = []
    for i in order:
        out.append({
            **chunks[int(i)],
            "keyword": float(kw[i]),
            "dense": float(dens[i]),
            "combined": float(combined[i]),
        })
    return out

# Smoke test on G-001
for row in hybrid_rank(
    "After theft, is rental car covered if the driver lives out of state?",
    alpha=0.5,
):
    print(f"{row['combined']:.3f} kw={row['keyword']:.2f} d={row['dense']:.3f}  {row['chunk_id']}")

Rerank + evaluate against data/rag_goldens.json

import json
from sentence_transformers import CrossEncoder

goldens = json.loads(Path("data/rag_goldens.json").read_text(encoding="utf-8"))["goldens"]
reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")

def rerank(query: str, candidates: list[dict], top_n: int = 3) -> list[dict]:
    pairs = [(query, row["text"]) for row in candidates]
    scores = reranker.predict(pairs)
    ranked = [{**row, "rerank_score": float(s)} for row, s in zip(candidates, scores)]
    ranked.sort(key=lambda r: r["rerank_score"], reverse=True)
    return ranked[:top_n]

def eval_goldens(alpha: float = 0.5) -> list[dict]:
    rows = []
    for g in goldens:
        q = g["question"]
        required = set(g["required_chunk_ids"])
        hybrid = hybrid_rank(q, alpha=alpha, top_n=5)
        hybrid_ids = [r["chunk_id"] for r in hybrid[:3]]
        ce = rerank(q, hybrid, top_n=3)
        ce_ids = [r["chunk_id"] for r in ce]
        rows.append({
            "question_id": g["question_id"],
            "hybrid_top3": hybrid_ids,
            "rerank_top3": ce_ids,
            "required": sorted(required),
            "hybrid_pass": required.issubset(set(hybrid_ids)),
            "rerank_pass": required.issubset(set(ce_ids)),
        })
    return rows

for row in eval_goldens():
    print(
        row["question_id"],
        "hybrid=", row["hybrid_pass"],
        "rerank=", row["rerank_pass"],
        "need=", row["required"],
    )
Chunk-id contract Goldens use ids like POL-HOME-010_water#burst-pipe-coverage. If your local heading slugger differs, map aliases or align headings before claiming a fail. The point of the exercise is the ranking pipeline, not brittle string equality. POL-HOME-010 is the parent policy; where a golden expects POL-HOME-FLOOD, that value identifies the rider expectation, not a replacement parent policy ID.
