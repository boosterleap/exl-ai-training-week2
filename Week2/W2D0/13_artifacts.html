Artifacts — publishing a shareable page directly from Claude Code

The last foundational topic before the capstone — and you'll use this exact capability for the Streamlit demo's write-up.

Concept

An Artifact is a rendered, hosted web page (or document) Claude Code can publish directly — useful for a dashboard, a report, or a demo page you want to share without setting up your own hosting. It starts private; you choose whether to share it further.

  • Different from a file in your repo. A file is code/content you and your team read in an editor. An artifact is something you'd hand a stakeholder a link to — rendered, presentable, no setup required on their end.
  • Updatable in place. Republishing to the same artifact updates it at the same URL — you don't get a new link every time you fix something.
