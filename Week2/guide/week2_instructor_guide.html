Week 2 topic coverage contract · 60 topics

The programme PDF’s 60 topics (10 sessions × 6 topics) are the authoritative coverage contract and are reproduced verbatim in every session below — unchanged from the original curriculum. What changed for this cohort is how each topic is delivered: no per-learner Anthropic API key, so wherever the original curriculum used a raw SDK/API script to demonstrate an agent-loop, tool, memory, or permission concept, this edition instead directs learners to operate and inspect Claude Code itself (which is built on those same primitives) or, where a topic needs a true outside call, uses the sandbox-provisioned AWS Bedrock path. The progressive implementation chains may combine multiple topics into one guided block for delivery, but no topic may be omitted. “Coverage/demo to verify” marks a visible implementation gap for later content-by-content review, not permission to skip the topic.

PDF topic coverage contract 01–06

  • 06 Data quality, lineage & freshness — an agent’s answer is only as good as the indexed, governed source behind it.
