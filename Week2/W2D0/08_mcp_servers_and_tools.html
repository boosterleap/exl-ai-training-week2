MCP servers & tools — a first look

A light primer — Week 2 Days 1–2 go much deeper (in-process vs. network servers, Streamable HTTP, permission gating). Here, just the registration mechanics.

Concept

MCP (Model Context Protocol) is how Claude Code gets custom tools beyond its built-ins. A server exposes one or more tools; you register it once, and Claude Code decides when to call it based on your request and the tool's description.

  • Readymade vs. custom. A readymade server (e.g. a Sentry or GitHub integration) is someone else's server you point at. A custom one is your own script exposing whatever your task needs — you'll build one for real in Week 2 Day 1.
  • One registration command either way. claude mcp add handles both — an HTTP URL for a hosted server, or a local command for your own stdio script.
