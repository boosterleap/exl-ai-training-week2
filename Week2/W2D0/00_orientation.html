What Claude Code actually is

Claude Code is an agentic coding tool: you give it a goal in plain language, and it reads files, runs commands, edits code, and reports back — the same perceive/reason/act/observe loop Week 2 Day 1 covers in depth, except you're the one directing it instead of building a toy version of it. Every mechanic in this track — memory files, permissions, hooks, subagents, MCP — is a real, load-bearing part of how it operates, not a simplified teaching example.

  • It's a real CLI and VS Code extension, already installed and logged in on your VM via subscription — confirmed with claude --version and claude auth status.
  • Everything here is verified against the live CLI (version 2.1.x as of this writing) — where a command's exact flags or output are shown, they were run for real, not guessed from documentation.

How to work through W2D0

  • Self-paced, no fixed timing. Work through 00–13 in order — each one builds on file conventions the previous one introduced. Budget roughly 15–25 min per topic.
  • Practice ground: this repository. Rather than a throwaway sandbox, you'll configure real slash commands, hooks, and subagents in this actual Week2-Claude repo — you'll use some of them again in Week 2 Days 1–5.
  • The capstone (14–18) is the payoff. A full EDA + ML + Streamlit project on the California Housing dataset, built stage by stage, tested, and deployed — entirely through Claude Code, with each stage's automation (git sync, testing) drawn directly from what 00–13 taught.
A note on scope This track teaches Claude Code's own mechanics using generic, no-domain examples. It does not touch the insurance/logistics data used in Week 2 Days 1–5 — that's intentional, so this track stands alone as a Claude Code primer regardless of when you take it.
