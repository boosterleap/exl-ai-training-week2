diskcache — semantic / response cache for retrieval-heavy agents

Retrieval agents pay for every cold question: embed, search, grade, sometimes regenerate. When operators ask the same policy question twice, you should not re-run that pipeline. This module teaches a durable local cache with diskcache, sha256 keys over normalized questions, cold vs warm benchmarks, separate bench namespaces, optional TTL, and the Day 3 PM GroundedAnswer caching pattern.

Why cache retrieval answers?

Day 3 PM builds exact and semantic cache behavior, benchmarks scope invalidation, then carries the result into a provider-backed Pinecone/Anthropic assistant and typed operator decision. That path is correct but expensive on repeats. A semantic response cache stores the finished payload under a key derived from the question text so the second ask is a disk lookup, not another retrieval round.

Cold path vs warm path Cold: Question → Retrieve / grade / generate (slow). Warm: Question → cache hit → cached GroundedAnswer with cache_hit=True (fast). The first successful answer is written into the store so later identical questions hit warm.

This is not vector similarity search. Keys are exact after normalization (lowercase + whitespace collapse), then hashed with sha256. Near-duplicates with different wording miss the cache — that is intentional and safer for policy answers.

Beginner Cache basics — open, set, get, persist

diskcache.Cache is a directory-backed key/value store. Values can be Python dicts (pickled). Keys are usually strings. Open a cache on a folder, write with cache[key] = value, read with cache[key] or membership key in cache.

Exercise B7 — Simulate expensive work only on miss

Fake a 50ms retrieval with time.sleep. First call pays; second call should skip sleep. 

from pathlib import Path
import time
import diskcache

cache = diskcache.Cache(str(Path("_scratch/b7_cache")))
cache.clear()

def retrieve(q: str) -> dict:
    key = q
    if key in cache:
        out = dict(cache[key])
        out["cache_hit"] = True
        return out
    time.sleep(0.05)
    payload = {"question": q, "answer": "stub", "cache_hit": False}
    cache[key] = payload
    return payload

t0 = time.perf_counter()
print(retrieve("G-001"), "ms", round((time.perf_counter() - t0) * 1000, 1))
t1 = time.perf_counter()
print(retrieve("G-001"), "ms", round((time.perf_counter() - t1) * 1000, 1))
cache.close()

Intermediate Keys, namespaces, GroundedAnswer pattern

Production ask paths never use the raw question string as the key. Day 3 PM normalizes whitespace and case, then hashes with sha256 so keys are fixed-length and filesystem-safe. Answer traffic and benchmark traffic use separate directories so cache-bench clears cannot wipe learner answers.

Normalization + sha256 (lab pattern)

from hashlib import sha256

def cache_key(question: str) -> str:
    """Normalize and hash a question for semantic cache lookup."""
    normalized = " ".join(question.lower().split())
    return sha256(normalized.encode("utf-8")).hexdigest()

Exercise I5 — Ask path: hit sets cache_hit True

Replicate the lab guard: on hit, require citations present; set cache_hit=True on the returned copy without mutating a stale idea of truth. 

from pathlib import Path
from hashlib import sha256
import diskcache

def cache_key(question: str) -> str:
    normalized = " ".join(question.lower().split())
    return sha256(normalized.encode("utf-8")).hexdigest()

cache = diskcache.Cache(str(Path("_scratch/semantic_cache")))
question = "After theft, is rental car covered if the driver lives out of state?"
key = cache_key(question)

def ask(question: str, no_cache: bool = False) -> dict:
    key = cache_key(question)
    if not no_cache and key in cache:
        payload = cache[key]
        if isinstance(payload, dict) and payload.get("citations") is not None:
            payload = dict(payload)
            payload["cache_hit"] = True
            return payload
        # incomplete/stale — fall through and rebuild
    # pretend retrieve+generate
    fresh = {
        "lane": "insurance",
        "question": question,
        "answer": "fresh build",
        "citations": [],
        "retrieval_steps": [],
        "session_id": None,
        "cache_hit": False,
        "sufficient_evidence": False,
    }
    cache[key] = fresh
    return fresh

print("1:", ask(question)["cache_hit"])
print("2:", ask(question)["cache_hit"])
print("bypass:", ask(question, no_cache=True)["cache_hit"])
cache.close()

Exercise I9 — Session-aware answers vs cache keys

Durable session facts can change the composed answer text. Discuss: should session_id be part of the key? For the default lab ask path, the key is question-only. If you cache session-flavored answers, include session in the key or you will serve the wrong customer facts. 

from hashlib import sha256

def cache_key(question: str, session_id: str | None = None) -> str:
    normalized = " ".join(question.lower().split())
    if session_id:
        normalized = f"{session_id}::{normalized}"
    return sha256(normalized.encode("utf-8")).hexdigest()

q = "Does garaging state change rental coverage?"
print(cache_key(q)[:12])
print(cache_key(q, "sess_cust_204_a")[:12])
print(cache_key(q, "sess_cust_204_b")[:12])
Intermediate takeaway Normalize → sha256 → store full GroundedAnswer dumps. Keep bench and answer directories separate. Validate cached payloads before trusting a hit.

Advanced Cold vs warm bench, TTL, invalidation, budgets

Day 3 PM assessment expects a cache benchmark with hits > 0 and faster cached lookup than cold retrieval. You will rebuild that microbench locally, then add TTL and invalidation knobs operators need when policies change.

Lab bench sketch

  1. Open open_bench_cache(), clear().
  2. Cold: run retrieve on a repeated question list (lab uses goldens × 34 ≈ 102 queries).
  3. Warm store once per unique question.
  4. Warm: loop again; count hits and time lookups only.
  5. Write cache_bench.json with cold_ms, warm_ms, speedup_x.
Exercise A1 — Mini cold vs warm bench

Use a fake retrieve with sleep. Separate bench directory. Report speedup. 

from pathlib import Path
from hashlib import sha256
import time
import json
import diskcache

def cache_key(question: str) -> str:
    normalized = " ".join(question.lower().split())
    return sha256(normalized.encode("utf-8")).hexdigest()

QUESTIONS = {
    "G-001": "After theft, is rental car covered if the driver lives out of state?",
    "G-002": "Is burst pipe water damage covered under homeowners?",
    "G-005": "Are emergency MRI scans covered without prior auth?",
}

def fake_retrieve(question: str) -> dict:
    time.sleep(0.01)
    return {"question": question, "steps": [1, 2]}

bench = diskcache.Cache(str(Path("_scratch/cache_bench_store")))
bench.clear()
queries = list(QUESTIONS.values()) * 10  # 30 queries

t0 = time.perf_counter()
for q in queries:
    fake_retrieve(q)
cold_ms = (time.perf_counter() - t0) * 1000

for q in QUESTIONS.values():
    key = cache_key(q)
    retrieval = fake_retrieve(q)
    bench[key] = {"question": q, "rounds": len(retrieval["steps"])}

t1 = time.perf_counter()
hits = 0
for q in queries:
    key = cache_key(q)
    if key in bench:
        hits += 1
        _ = bench[key]
warm_ms = (time.perf_counter() - t1) * 1000

payload = {
    "queries": len(queries),
    "cold_retrieval_ms": round(cold_ms, 2),
    "cached_lookup_ms": round(warm_ms, 2),
    "cache_hits": hits,
    "speedup_x": round(cold_ms / warm_ms, 2) if warm_ms else None,
    "lesson": "Semantic cache removes repeat retrieval work on identical questions.",
}
out = Path("_scratch/outputs")
out.mkdir(parents=True, exist_ok=True)
path = out / "cache_bench.json"
path.write_text(json.dumps(payload, indent=2), encoding="utf-8")
print(payload)
print("Wrote", path)
bench.close()

Exercise A6 — Budget interaction

Cache hits should not consume retrieval rounds from RAG_MAX_ROUNDS. Track a simple counter: only increment on miss. 

from pathlib import Path
from hashlib import sha256
import diskcache

def cache_key(question: str) -> str:
    normalized = " ".join(question.lower().split())
    return sha256(normalized.encode("utf-8")).hexdigest()

RAG_MAX_ROUNDS = 3
retrieval_calls = 0
cache = diskcache.Cache(str(Path("_scratch/a6_budget")))
cache.clear()

def ask(q: str) -> dict:
    global retrieval_calls
    key = cache_key(q)
    if key in cache:
        hit = dict(cache[key])
        hit["cache_hit"] = True
        hit["retrieval_calls_so_far"] = retrieval_calls
        return hit
    retrieval_calls += 1  # pays budget
    rounds = min(2, RAG_MAX_ROUNDS)
    payload = {"question": q, "rounds": rounds, "cache_hit": False}
    cache[key] = payload
    payload = dict(payload)
    payload["retrieval_calls_so_far"] = retrieval_calls
    return payload

qs = ["theft rental?", "theft rental?", "burst pipe?"]
for q in qs:
    print(ask(q))
print("retrieval_calls", retrieval_calls)  # expect 2
cache.close()

Exercise A9 — What not to cache

List three payloads that should stay uncached or use short TTL. Write a gate function. 

def should_cache(payload: dict) -> bool:
    """Only cache grounded answers with evidence."""
    if not payload.get("sufficient_evidence", False):
        return False
    if not payload.get("citations"):
        return False
    if payload.get("lane") not in {"insurance", "banking", "logistics"}:
        return False
    return True

good = {"lane": "insurance", "citations": [{}], "sufficient_evidence": True}
bad = {"lane": "insurance", "citations": [], "sufficient_evidence": False}
print(should_cache(good), should_cache(bad))
