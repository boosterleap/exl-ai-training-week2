tenacity — retries, exponential backoff, model/path fallback

Production agents call flaky upstreams: carrier APIs time out, LLM providers return 429s, secondary lookup paths degrade. tenacity makes retry policy declarative. This module walks Beginner → Advanced with offline simulators only — no network, no API keys. The running story is the logistics lane: container status lookup with a primary path, a cheaper fallback, step/cost budgets, and attempt logging.

Why retries belong in the agent scaffold

Week 2 Day 2 PDF topic 05 — Reliability engineering pairs with the instructor demo at 14:40: Retry + model fallback on the logistics lane. Retries are not “try harder forever.” They are a bounded policy:

  • What to retry (transient only — e.g. FlakyError)
  • How long to wait (exponential backoff, capped)
  • When to stop (attempt cap, then fallback or fail)
  • How much it costs (each attempt burns a step and/or USD)

Beginner FlakyError simulator & basic @retry

Goal: replace a manual while loop with @retry(stop=stop_after_attempt(...)). All demos are in-process counters — zero network.

Concept — FlakyError

class FlakyError(RuntimeError):
    """Simulated transient upstream failure (timeout / 503)."""


def primary_lookup(container_id: str, attempts: dict) -> dict:
    attempts["primary"] += 1
    if attempts["primary"] < 3:
        raise FlakyError("temporary upstream timeout")
    return {
        "provider": "primary",
        "container_id": container_id,
        "status": "in_transit",
    }

Concept — first successful retry

from tenacity import retry, stop_after_attempt

attempts = {"n": 0}

@retry(stop=stop_after_attempt(3))
def unstable_read() -> str:
    attempts["n"] += 1
    if attempts["n"] < 2:
        raise RuntimeError("transient read failure")
    return "data-ok"

attempts["n"] = 0
print(unstable_read(), "after", attempts["n"], "attempt(s)")
# Expected: data-ok after 2 attempt(s)

Intermediate Backoff, typed retries, attempt logging

Goal: only retry transient errors, space attempts with wait_exponential, and log each sleep so operators see what the agent is waiting on.

Concept — wait_exponential

import time
from tenacity import retry, stop_after_attempt, wait_exponential

times: list[float] = []

@retry(
    stop=stop_after_attempt(4),
    wait=wait_exponential(multiplier=0.05, min=0.05, max=0.2),
)
def call_with_backoff() -> str:
    times.append(time.time())
    if len(times) < 3:
        raise ConnectionError("503 service unavailable")
    return "success"

print(call_with_backoff())
gaps = [round(times[i] - times[i - 1], 3) for i in range(1, len(times))]
print("Wait gaps (s):", gaps)
# Classroom tip: keep multiplier tiny so demos finish in <1s.

Concept — retry_if_exception_type

from tenacity import retry_if_exception_type

@retry(
    reraise=True,
    stop=stop_after_attempt(3),
    retry=retry_if_exception_type(FlakyError),
)
def call_carrier(simulate: str) -> str:
    if simulate == "timeout":
        raise FlakyError("upstream timeout")
    if simulate == "bad_id":
        raise ValueError("invalid container id — do not retry")
    return "ok"

# ValueError must fail immediately (1 attempt). FlakyError may retry.

Custom callback (often clearer in notebooks than stdlib logging):

def log_attempt(retry_state):
    exc = retry_state.outcome.exception() if retry_state.outcome else None
    print(
        f"[retry] attempt={retry_state.attempt_number} "
        f"next_wait={retry_state.next_action.sleep if retry_state.next_action else None} "
        f"exc={type(exc).__name__ if exc else None}"
    )

@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=0.05, min=0.05, max=0.1),
    before_sleep=log_attempt,
    reraise=True,
)
def demo():
    raise FlakyError("blip")

Advanced Primary → fallback + step/cost budgets

Goal: compose the full Day 2 reliability story — retry primary, fall back when exhausted, and hard-stop the agent loop when step or spend budgets trip. Pure Python; offline.

Concept — primary then fallback

from tenacity import retry, stop_after_attempt, wait_exponential, retry_if_exception_type

class FlakyError(RuntimeError):
    """Simulated transient upstream failure."""


def primary_lookup(container_id: str, attempts: dict) -> dict:
    attempts["primary"] += 1
    if attempts["primary"] < 3:
        raise FlakyError("temporary upstream timeout")
    return {
        "provider": "primary",
        "container_id": container_id,
        "status": "in_transit",
    }


def fallback_lookup(container_id: str, attempts: dict) -> dict:
    attempts["fallback"] += 1
    return {
        "provider": "fallback",
        "container_id": container_id,
        "status": "unknown_degraded",
        "note": "Returned by fallback after primary retries failed.",
    }


def lookup_with_reliability(container_id: str) -> dict:
    attempts = {"primary": 0, "fallback": 0}

    @retry(
        reraise=True,
        stop=stop_after_attempt(3),
        wait=wait_exponential(multiplier=0.05, min=0.05, max=0.2),
        retry=retry_if_exception_type(FlakyError),
    )
    def _primary() -> dict:
        return primary_lookup(container_id, attempts)

    try:
        result = _primary()
        mode = "primary_after_retry"
    except FlakyError:
        result = fallback_lookup(container_id, attempts)
        mode = "fallback"

    return {"mode": mode, "attempts": attempts, "result": result}


print(lookup_with_reliability("MSKU123"))
# mode primary_after_retry, attempts primary=3, fallback=0

Concept — step & cost budgets

MAX_STEPS = 3
MAX_BUDGET_USD = 0.05

def run_with_budgets(steps: list[dict]) -> dict:
    spent = 0.0
    completed = []
    stop_reason = "completed"
    for index, step in enumerate(steps, start=1):
        if index > MAX_STEPS:
            stop_reason = "max_steps"
            break
        spent += float(step["cost_usd"])
        if spent > MAX_BUDGET_USD:
            stop_reason = "max_budget_usd"
            break
        completed.append(step)
    return {
        "completed_steps": len(completed),
        "spent_usd": round(spent, 4),
        "stop_reason": stop_reason,
        "limits": {"max_steps": MAX_STEPS, "max_budget_usd": MAX_BUDGET_USD},
    }
 Agent loop (one turn)
 -------------------------------------------------
 | plan -> tool call -> observe -> ...            |
 |                                               |
 | each tool call:                               |
 |   1) budget gate (steps / USD)                |
 |   2) tenacity retry on primary path           |
 |   3) on exhaustion -> fallback path           |
 |   4) log attempts for the operator summary    |
 -------------------------------------------------

Quick reference & pitfalls

PatternSnippet
Minimal retry @retry(stop=stop_after_attempt(3))
Backoff wait=wait_exponential(multiplier=0.05, min=0.05, max=0.2)
Typed retry=retry_if_exception_type(FlakyError)
Reraise last reraise=True
Log sleeps before_sleep=before_sleep_log(log, logging.INFO)
Fallback try: primary() except FlakyError: fallback()
Pitfalls Retrying non-idempotent writes · retrying validation errors · uncapped stop_never in production · long classroom waits · forgetting that each retry consumes step/cost budget · swallowing errors without operator summary.

Ship checklist (Day 2 reliability)

  • FlakyError simulator fails then succeeds under @retry
  • Only transient types retried via retry_if_exception_type
  • wait_exponential capped for demos and for production
  • Primary exhaustion → fallback path (degraded status or cheaper model)
  • Attempts logged (before_sleep or custom)
  • Step and USD budgets hard-stop the loop
  • Write tools (hold release) stay approval + idempotency gated — not blind-retried
