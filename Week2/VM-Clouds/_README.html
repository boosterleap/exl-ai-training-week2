VM and Cloud Sandbox Guides

Fast setup for Day 2: prepare the Ubuntu VM first, then open only the provider guide required for your session.

Purpose Required order Sessions Safeguards Guides

Purpose

Use these guides to prepare your course VM and the time-limited cloud sandbox needed for the current Day 2 exercise.

Required order

  1. Complete the Ubuntu VM setup guide.
  2. Follow the relevant provider guide immediately before that provider's session.
Separate authentication boundary: browser access inside a cloud sandbox does not automatically authenticate the Ubuntu VM. Each provider guide explains how to establish approved VM-compatible access.

Day 2 session map

  • Day 2 AM: GCP (Google ADK) and Azure (Microsoft Agent Framework) are instructor-demo only this cohort — the instructor runs the linked guides live during the framework-landscape topic; learners watch, no learner setup needed for either.
  • Day 2 PM, Topic 4: AWS is the one hands-on cloud exercise — every learner completes the Bedrock guide themselves.

Shared safeguards

  • No secret is ever written to a file in the shared repo — the AWS Bedrock key (the one learner-facing secret this week) is exported directly into the terminal session for that one exercise and unset afterward; GCP uses ADC (no key at all); Azure's key is instructor-only.
  • Never commit secrets, tokens, credentials, or key files.
  • Stop the cloud sandbox as soon as the exercise ends.
Moving a secret from a cloud sandbox browser to the VM: the sandboxes share no clipboard. Use syncclip.in — paste the value into it from the cloud sandbox browser tab, note the sync code, then retrieve it on the VM's own browser with the same code. The AWS guide walks through this exact sequence at the point it's needed.
