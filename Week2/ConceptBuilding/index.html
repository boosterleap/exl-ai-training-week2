How to use

  1. From Week2: create/activate venv and uv pip install -r requirements.txt (Module 01 shows Windows and Ubuntu activation).
  2. Install a Jupyter kernel (module 01), open a blank notebook, set working directory to Week2/ConceptBuilding (or adjust paths).
  3. Work modules in order. Do every exercise before advancing a level.
  4. When a module needs API keys, copy Week2/.env.example to Week2/.env — never commit secrets.
Windows PowerShell — .env once
# cwd: Week2
copy .env.example .env
Ubuntu / bash — .env once
# cwd: Week2
cp .env.example .env
