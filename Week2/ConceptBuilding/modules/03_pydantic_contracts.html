Why contracts matter

Without a contract, an agent can invent field names, drop required keys, or format claim ids as bare digits. A Pydantic model rejects bad payloads early and returns a clear ValidationError the planner can recover from. 

  agent JSON args / structured reply
            |
            v
   +------------------+
   |  Pydantic model  |  model_validate / model_validate_json
   +--------+---------+
            |
     ok? ---+--- no ---> ValidationError (tell planner)
            |
           yes
            |
            v
   typed Python object ---> tool body / TriageDecision / CostLog
            |
            v
   model_dump() / model_dump_json() ---> logs, APIs, CLI ship artifact
Operator-facing rule Never invent claim, loan, policy, or shipment records. Contracts validate shape; domain tools supply facts. Write ops (goodwill credit, hold release) need learner approval plus an idempotency key.

from typing import Literal

from pydantic import BaseModel, Field, ValidationError


class ClaimIdOnly(BaseModel):

class TriageDecision(BaseModel):
    """Final structured decision returned by the operations assistant."""

    lane: Literal["insurance", "banking", "logistics"] = Field(
        ..., description="Domain lane that produced the decision"
    )
    case_id: str = Field(
        ..., description="Primary case identifier (claim id, loan id, or container id)"
    )
    urgency: Literal["low", "medium", "high"] = Field(
        ..., description="Operational urgency for queueing"
    )
    route_queue: str = Field(..., description="Destination work queue or team")
    summary: str = Field(..., description="One-sentence operator-facing summary")
    rationale: str = Field(..., description="Why this routing and urgency were chosen")
    tools_used: list[str] = Field(default_factory=list)
    confidence: float = Field(..., ge=0.0, le=1.0)
    needs_human_approval: bool = False

Advanced Validators, idempotency, CostLog, forbid extra, agent output

Goal: harden contracts for production-style agent loops — custom validators, write-tool keys, cost budgets, reject unknown fields, and wire schemas into structured model output.

Concept — field_validator & model_validator

from pydantic import BaseModel, Field, field_validator, model_validator


class ClaimRef(BaseModel):
    claim_id: str = Field(..., pattern=r"^CLM-\d{6}$")

    @field_validator("claim_id")
    @classmethod
    def uppercase_prefix(cls, v: str) -> str:
        # normalize accidental lowercase prefix
        if v.lower().startswith("clm-"):
            return "CLM-" + v.split("-", 1)[1]
        return v

Concept — Idempotency key model

class WriteActionRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")

    action: Literal["goodwill_credit", "release_hold"]
    case_id: str
    idempotency_key: str = Field(
        ...,
        min_length=8,
        max_length=128,
        pattern=r"^[A-Za-z0-9._:-]+$",
        description="Caller-supplied unique key; retries reuse the same receipt",
    )
    amount_usd: float | None = Field(default=None, ge=0)
    reason: str | None = None

    @model_validator(mode="after")
    def credit_needs_amount(self) -> "WriteActionRequest":
        if self.action == "goodwill_credit" and self.amount_usd is None:
            raise ValueError("goodwill_credit requires amount_usd")
        if self.action == "release_hold" and not self.reason:
            raise ValueError("release_hold requires reason")
        return self

Concept — CostLog (budget telemetry)

class CostLog(BaseModel):
    """Cost, token, and step telemetry written next to each run."""

    session_id: str | None = None
    provider: str
    model: str
    lane: str
    steps_used: int
    max_steps: int
    input_tokens: int = 0
    output_tokens: int = 0
    total_tokens: int = 0
    max_tokens: int
    total_cost_usd: float | None = None
    max_budget_usd: float | None = None
    stopped_reason: str

    @model_validator(mode="after")
    def within_budgets(self) -> "CostLog":
        if self.steps_used > self.max_steps:
            raise ValueError("steps_used exceeds max_steps")
        if self.total_tokens > self.max_tokens:
            raise ValueError("total_tokens exceeds max_tokens")
        if (
            self.max_budget_usd is not None
            and self.total_cost_usd is not None
            and self.total_cost_usd > self.max_budget_usd
        ):
            raise ValueError("total_cost_usd exceeds max_budget_usd")
        return self

API cheat sheet (June 2026 · Pydantic v2)

APIUse
BaseModel Declare a contract
Field(...) Constraints, defaults, descriptions, patterns
Literal[...] Closed enums for lanes, urgency, status
ConfigDict Model config; prefer extra="forbid" on tool inputs
Model.model_validate(data) Parse dict / object
Model.model_validate_json(s) Parse JSON string from model/tool
obj.model_dump() Python dict (optionally mode="json")
obj.model_dump_json() JSON string for logs / CLI ship
Model.model_json_schema() JSON Schema for tools & structured output
field_validator / model_validator Normalize and cross-field rules
ValidationError.errors() Machine-readable repair hints
