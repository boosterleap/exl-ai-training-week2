Why Agent Cards

Module 09 covered MCP: agent → tool/server. This module covers A2A: agent → agent. You do not invent peer APIs ad hoc; you publish a card the planner (or supervisor) can read, then hand off only skills the card declares.

ProtocolConnectsDay 2 lab artifact
MCP Agent → tool / server Inventory stock lookup (inventory_server.py)
A2A Agent → agent agent_card.json + planner → comms handoff
ACP → A2A Older Agent Communication Protocol (ACP) ideas for agent identity and discovery are treated here as merged into A2A under the Linux Foundation. Classroom vocabulary is A2A + Agent Cards. Do not teach a separate ACP stack in Week 2.
Local simulation only Lab code loads a JSON file and simulates handoff. It is not a remote A2A wire protocol, registry crawl, or streaming task session. Say that out loud when you demo.

Exercise I1 — Pydantic AgentCard model

Define nested models for Skill, Authentication, Capabilities, and AgentCard. Validate your lab JSON. 

from pydantic import BaseModel, Field

class Skill(BaseModel):
    id: str
    description: str

class Authentication(BaseModel):
    schemes: list[str]

class Capabilities(BaseModel):
    streaming: bool = False
    pushNotifications: bool = False

class AgentCard(BaseModel):
    name: str
    description: str
    url: str
    version: str = "0.1.0"
    protocol: str = "a2a"
    skills: list[Skill]
    authentication: Authentication
    capabilities: Capabilities = Field(default_factory=Capabilities)

card = AgentCard.model_validate(agent_card)
print(card.name, [s.id for s in card.skills])

Exercise I3 — get_stock helper

Implement get_stock(sku) against data/inventory.json. Return found flag, qty, reorder_point, and source: "local_file". 

def get_stock(sku: str) -> dict:
    inv = json.loads(Path("data/inventory.json").read_text(encoding="utf-8"))
    for item in inv["items"]:
        if item["sku"] == sku:
            return {
                "found": True,
                "sku": sku,
                "name": item["name"],
                "qty_on_hand": item["qty_on_hand"],
                "reorder_point": item["reorder_point"],
                "warehouse": inv["warehouse"],
                "source": "local_file",
            }
    return {"found": False, "sku": sku, "source": "local_file"}

print(get_stock("SKU-1002"))
print(get_stock("SKU-9999"))
Exercise I4 — Planner decide

Mirror Day 2: handoff when found and qty ≤ reorder. Test SKU-1002 (should hand off) and SKU-1001 (healthy). 

def planner_decide(sku: str) -> dict:
    stock = get_stock(sku)
    needs = bool(stock.get("found")) and stock["qty_on_hand"] <= stock["reorder_point"]
    return {
        "stock": stock,
        "handoff": needs,
        "message": (
            f"SKU {sku} is at or below reorder point."
            if needs
            else f"SKU {sku} has healthy stock."
        ),
    }

print(planner_decide("SKU-1002"))
print(planner_decide("SKU-1001"))

def comms_agent_handle(message: str, card: dict) -> dict:
    skill_ids = {s["id"] for s in card["skills"]}

    return {

        "skill_used": skill,
        "notification": message,
        "status": "queued",

Exercise I8 — Discovery mode switch (concept)

Write a function load_card(mode, path=None, url=None) that loads from file when mode=="local_file", and raises NotImplementedError for network with a clear message. 

def load_card(mode: str, path: str | None = None, url: str | None = None) -> dict:
    if mode == "local_file":
        assert path, "path required for local_file"
        return json.loads(Path(path).read_text(encoding="utf-8"))
    if mode == "network":
        raise NotImplementedError(
            f"network discovery not in Week 2 lab (would fetch {url}). Use local_file."
        )
    raise ValueError(f"unknown discovery mode: {mode}")

print(load_card("local_file", path="data/agent_card_lab.json")["name"])
try:
    load_card("network", url="https://example.invalid/.well-known/agent.json")
except NotImplementedError as exc:
    print("expected:", exc)

Exercise A1 — Skill-gated handoff

Change comms so the caller must pass skill_id. Reject unknown skills with a structured error dict (do not raise) so planners can log it. 

def comms_agent_handle_gated(message: str, card: dict, skill_id: str) -> dict:
    skill_ids = {s["id"] for s in card["skills"]}
    if skill_id not in skill_ids:
        return {
            "agent": card["name"],
            "skill_used": None,
            "status": "rejected",
            "error": f"skill_not_on_card:{skill_id}",
        }
    return {
        "agent": card["name"],
        "skill_used": skill_id,
        "notification": message,
        "status": "queued",
    }

print(comms_agent_handle_gated("low stock", agent_card, "notify_delay"))
print(comms_agent_handle_gated("low stock", agent_card, "release_hold"))
Exercise A2 — Choose skill from message intent

If message contains “reorder” or “stock”, use notify_delay; if it contains “summary” or “status”, use summarize_shipment; else reject. 

def pick_skill(message: str) -> str | None:
    m = message.lower()
    if "reorder" in m or "stock" in m or "below" in m:
        return "notify_delay"
    if "summary" in m or "status" in m:
        return "summarize_shipment"
    return None

msg = planner_decide("SKU-1002")["message"]
skill = pick_skill(msg)
print(msg, "→", skill)
print(comms_agent_handle_gated(msg, agent_card, skill or "missing"))
Exercise A3 — Auth gate stub

Add require_auth(card, token). If schemes is only none, allow any token including None. If schemes include bearer, require token == "lab-secret". 

def require_auth(card: dict, token: str | None) -> bool:
    schemes = card["authentication"]["schemes"]
    if schemes == ["none"]:
        return True
    if "bearer" in schemes:
        return token == "lab-secret"
    return False

secure_card = json.loads(json.dumps(agent_card))
secure_card["authentication"]["schemes"] = ["bearer"]
print("lab none:", require_auth(agent_card, None))
print("bearer bad:", require_auth(secure_card, "nope"))
print("bearer ok:", require_auth(secure_card, "lab-secret"))

Exercise A5 — Idempotency key on handoff

Operator-facing handoffs should be replay-safe. Add idempotency_key = f"{sku}:{skill_used}" to each queued result. Deduplicate a replayed list. 

def with_idempotency(sku: str, result: dict) -> dict:
    out = dict(result)
    out["idempotency_key"] = f"{sku}:{result.get('skill_used')}"
    return out

raw = [with_idempotency(r["sku"], r["comms"]) for r in records]
raw_replay = raw + raw  # accidental double send
seen = set()
deduped = []
for row in raw_replay:
    key = row["idempotency_key"]
    if key in seen:
        continue
    seen.add(key)
    deduped.append(row)
print("raw", len(raw_replay), "deduped", len(deduped))

Exercise A8 — Operator summary for Day 2 ship

Write a function that returns a concise operator-facing summary string for a completed handoff payload (warehouse, SKU, skill, status, discovery mode). Print it for SKU-1002. 

def operator_summary(payload: dict) -> str:
    stock = payload["planner"]["stock"]
    comms = payload["comms_result"]
    mode = payload.get("discovery", {}).get("mode", "local_file")
    return (
        f"[{stock.get('warehouse')}] {stock.get('sku')} "
        f"qty={stock.get('qty_on_hand')}/{stock.get('reorder_point')} → "
        f"handoff {comms['agent']} skill={comms['skill_used']} "
        f"status={comms['status']} discovery={mode}"
    )
