Why a single codebase

Week 1 often duplicated notebooks with provider suffixes. That pattern breaks down once the lab is a multi-file agent: schemas, tools, CLI, sessions, cost logs, and permission gates would drift between copies. Week 2 keeps one scaffold per day. Cohort assignment is an env flag only.

ApproachWhat learners openFailure mode
Dual folders (W2D1PM/ + W2D1PM_openrouter/) Wrong tree if mis-assigned Schema/tool patches land in one copy only
Single folder + LLM_PROVIDER Same d1pmt6c02_guarded_operations_assistant.py for everyone Incorrectly configured .env — easy to fix without forking code
Instructor rule Assign provider before Day 1 PM. Learners never hunt for an _openrouter tree. Routing lives in the provider factory, not in folder layout.

Day 1 PM dual-provider map

The Agentic Operations Assistant is the first place learners see the factory in a real lab. AM may still discuss Claude Agent SDK concepts on slides; the PM runtime path depends on the cohort flag. 

d1pmt6c02_guarded_operations_assistant.py
  |- --dry-run  → tools-only TriageDecision (no API spend)
  `- provider   → providers.run_provider_agent(...)
                    |- anthropic  → ClaudeSDKClient + in-process MCP tools
                    `- openrouter → LangGraph ReAct + LangChain tools
                  → same TriageDecision JSON + CostLog shape
LLM_PROVIDERRuntimeKeys / model env
anthropic Claude Agent SDK ANTHROPIC_API_KEY, ANTHROPIC_MODEL
openrouter LangGraph + OpenAI-compatible client OPENROUTER_API_KEY, OPENROUTER_BASE_URL, OPENROUTER_MODEL
Shared contract Both paths must return a valid TriageDecision, honor write permission gating, and emit a cost log. If only one provider can do that, the factory is incomplete — fix the runtime, do not fork the CLI.

Model ID naming (June 2026)

Anthropic’s native API and OpenRouter’s catalog use different string formats for related Claude models. Mixing them is a common Day 1 PM failure.

ProviderEnv varDefault lab modelNotes
Anthropic SDK ANTHROPIC_MODEL claude-sonnet-4-6 Native Anthropic model id (June 2026 lab default)
OpenRouter OPENROUTER_MODEL anthropic/claude-sonnet-4 Vendor-prefixed OpenRouter slug; not the native id 
# Anthropic cohort (.env)
LLM_PROVIDER=anthropic
ANTHROPIC_MODEL=claude-sonnet-4-6

# OpenRouter cohort (.env)
LLM_PROVIDER=openrouter
OPENROUTER_MODEL=anthropic/claude-sonnet-4
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
Rule of thumb Never hard-code one model string for both branches. Resolve the model after you know provider, exactly like load_settings() in Day 1 PM.

from typing import Any

def load_settings(environ: dict[str, str]) -> dict[str, Any]:
    provider = environ.get("LLM_PROVIDER", "anthropic").lower()
    if provider not in {"anthropic", "openrouter"}:
        raise ValueError(f"unsupported LLM_PROVIDER: {provider}")
    model = (
        environ.get("OPENROUTER_MODEL", "anthropic/claude-sonnet-4")
        if provider == "openrouter"
        else environ.get("ANTHROPIC_MODEL", "claude-sonnet-4-6")
    )
    return {
        "provider": provider,
        "model": model,
        "max_steps": int(environ.get("AGENT_MAX_STEPS", "10")),
        "max_tokens": int(environ.get("AGENT_MAX_TOKENS", "8000")),
        "max_budget_usd": float(environ.get("AGENT_MAX_BUDGET_USD", "0.50")),
        "base_url": environ.get("OPENROUTER_BASE_URL", "https://openrouter.ai/api/v1")
        if provider == "openrouter"
        else None,
    }

s = load_settings({"LLM_PROVIDER": "openrouter"})
assert s["model"] == "anthropic/claude-sonnet-4"
assert s["base_url"].endswith("/api/v1")
print("I1 OK", s["provider"], s["model"])

        "max_budget_usd": float(environ.get("AGENT_MAX_BUDGET_USD", "0.50")),
        "base_url": (
            environ.get("OPENROUTER_BASE_URL", "https://openrouter.ai/api/v1")
            if provider == "openrouter"
            else None
        ),
    }

def run_provider_agent(prompt: str, environ: dict[str, str]) -> dict[str, Any]:
    settings = load_settings(environ)
    runtime = (
        "langgraph_openai_compatible"
        if settings["provider"] == "openrouter"
        else "claude_agent_sdk"
    )
    return {
        "provider": settings["provider"],
        "model": settings["model"],
        "runtime": runtime,
        "answer_text": f"[{settings['provider']}] {prompt}",
        "cost": {"steps_used": 1, "stopped_reason": "mock"},
    }

assert run_provider_agent("ping", {})["model"] == "claude-sonnet-4-6"
